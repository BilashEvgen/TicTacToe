# Tic Tac Toe

A classic Tic Tac Toe game built with Python and the Turtle graphics library.

## Description

Two players take turns placing Xs and Os on a 3×3 grid. The game automatically detects wins and draws.

## Features

* Graphical game board
* Mouse controls
* Automatic win detection
* Draw detection
* Winning line visualization

## Running the Game

```bash
python "tic tac toe.py"
```

## Technologies Used

* Python
* Turtle Graphics

## Learning Goals

This project was created to practice:

* Turtle graphics
* Mouse click handling
* List manipulation
* Game logic implementation
* Basic GUI programming
